# Environment Configuration

This project uses different `.env` files for different environments.

## Files

- **`.env.dev`** - Development environment (used when `NODE_ENV=development`)
- **`.env.production`** - Production environment (used when `NODE_ENV=production`)
- **`.env.example`** - Template file (commit to git)

## Setup

1. Copy `.env.example` to `.env.dev` for local development:

    ```bash
    cp .env.example .env.dev
    ```

2. Fill in your development credentials in `.env.dev`

3. For production, create `.env.production` with production credentials

## Usage

The BFF picks its env file from `NODE_ENV`: `development` loads `.env.dev`, anything else loads `.env.production`.

**Development:**

```bash
npm start                  # Angular dev server (:4200) + BFF (:4000, tsx watch) with .env.dev
npm run build:dev          # Build SPA + BFF bundle
npm run serve:dev          # Run the built BFF with .env.dev
```

**Production:**

```bash
npm run build              # Build SPA + BFF bundle
npm run serve              # Run the built BFF with .env.production (serves API + SPA)
```

## Git

- ✅ Commit: `.env.example`, `.env.README.md`
- ❌ Never commit: `.env.dev`, `.env.production`

Make sure `.env.dev` and `.env.production` are in `.gitignore`
